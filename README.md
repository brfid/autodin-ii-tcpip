# AUTODIN II and TCP/IP

Historical research on AUTODIN II requirements, the development of TCP/IP, and the 1981–82 Defense Data Network decision. The main question is which connections the surviving documents establish, and which causal explanations remain unproved. Later standards and the BLACKER interface have separate notebooks.

Start with the [research overview](research.md), then follow a subject into its evidence. The [open questions](questions.md) identify the most consequential missing records.

The records are ordinary Markdown, with structured provenance where exact page mappings or fingerprints are useful. Existing online originals are linked directly. Selected scans without an authenticated equivalent are under `sources/unique/` and use Git LFS for binary files; [GitHub’s LFS instructions](https://docs.github.com/en/repositories/working-with-files/managing-large-files/installing-git-large-file-storage) explain how to obtain their full contents when cloning. No build is needed.
