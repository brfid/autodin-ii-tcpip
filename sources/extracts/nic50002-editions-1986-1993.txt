Chunk 5c pass, 14 September 2026. Verbatim entries for the BLACKER Front End
Interface Control Document and the DDN Subscriber Security Guide, in edition order.

Cover dates are read from each document's own title page, not from catalogue
metadata. Every PDF was taken from the Internet Archive DTIC mirror
(https://archive.org/download/DTIC_ADAnnnnnn/DTIC_ADAnnnnnn.pdf); apps.dtic.mil
returned HTTP 403 on the single probe run in this pass. Text below is from
pdftotext -layout (discovery); the four passages marked INSPECTED were read as
